4. DONNÉES ET VIE PRIVÉE
RedChat ne dispose d'aucun serveur central : vos messages circulent directement entre les appareils que vous connectez.
Vos données (profil, contacts, historique, pièces jointes reçues) sont enregistrées sur votre appareil, dans votre

Il vous appartient de protéger l'accès à votre session Windows et de sauvegarder vos données si nécessaire.
Un journal technique local (sans contenu de message ni clé) peut être écrit pour faciliter le dépannage.
